# SRS-M-nimo-Nombre-del-proyecto-PanPedido.github.io
PanPedido es un sistema web que permite a una panadería registrar sus productos, gestionar los pedidos de los clientes indicando la hora de retiro y controlar la entrega de cada pedido. El objetivo es organizar las ventas y reducir errores durante la atención.
El sistema permite
Registrar productos de la panadería.
Registrar pedidos indicando la hora de retiro.
Marcar los pedidos como entregados.
El sistema NO permite
Pagos en línea.
Facturación electrónica.
Servicio de entrega a domicilio.
Gestión de proveedores.
